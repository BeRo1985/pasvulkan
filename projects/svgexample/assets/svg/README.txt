tiger.svg

The tiger that has been used to show off vector graphics renderers since the PostScript days,
originally an Adobe Illustrator sample and part of the Ghostscript examples. Public domain.

It is a good test case for the vector path route of the canvas, because all 240 of its paths are
filled with a plain color and stroked, with no gradient, pattern, mask or filter anywhere, so the
whole document goes through the shader.
